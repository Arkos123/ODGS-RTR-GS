# [cal_diffuse](./prt_utils.py#L8)

用户问怎么理解 `ReLU(Σ(c_j · c_j^t) + 0.5)` 这个公式，为什么这么算。这是一个关于PRT理论的问题，我需要从两个层面来解释：

1. **物理层面**：为什么漫反射颜色 = 反照率 × 传输函数？（即为什么 `C_d = ρ_d · T`）
2. **数学层面**：为什么传输函数 T = ReLU(Σ(c_j · c_j^t) + 0.5)？为什么是点积？为什么加0.5偏置？为什么用ReLU？

让我从PRT理论和SH投影的角度来推理：

**1. 基本物理**
漫反射遵循 Lambertian 定律，出射辐射率 = 反照率 × 入射辐射率。
C_d = ρ_d · L_d

**2. PRT 的思路**
入射辐射率 L_d 由场景光照和物体几何/遮挡共同决定。PRT把光照和传输（几何+遮挡）分开：
- 光照（lighting）：用 SH 表示场景的入射光分布 c_j
- 传输（transfer）：每个点预计算一个传输函数，同样用 SH 投影表示 c_j^t

为什么要用点积？
一个函数（光照分布）在 SH 基下的系数与另一个函数（传输 BRDF 传输函数）在 SH 基下的系数做点积，等于这两个函数乘积的积分（SH 的正交性）：
∫ L(ω) · T(ω) dω ≈ Σ(c_j · c_j^t)

这里的 c_j 是光照在 SH 基下的投影系数，c_j^t 是传输函数在 SH 基下的投影系数。

所以 Σ(c_j · c_j^t) 其实就是入射光经过传输（遮挡/阴影等调制后）在接收点的总能量。

**3. 为什么 +0.5 偏置？**
这是一个实践经验（heuristic）：
- 理论上 Σ(c_j · c_j^t) 可能为负（SH 系数有正有负，因为 SH 基函数有正负区域）
- 但物理上传输能量不能为负
- +0.5 提供了一个基线环境光，保证即使在光照最不利的情况下也有基本亮度
- 也可以理解为一个环境光项（ambient term），类似图形学中的 ambient occlusion + constant ambient light

**4. 为什么 ReLU？**
物理上，传输能量必须非负。ReLU 保证输出 ≥ 0。

所以整体来看，这个公式在做的其实就是：
1. 把光照投射到 SH 基 → c_j
2. 把每个 Gaussian 点的传输函数也投射到 SH 基 → c_j^t  
3. SH 投影系数的点积 ≈ 光照经过传输后的积分 → Σ(c_j · c_j^t)
4. 加一个环境光 baseline → +0.5
5. 确保非负 → ReLU
6. 乘以反照率得到最终漫反射颜色 → ρ_d · ReLU(...)

这本质上就是一个 SH 域上的"光照 × 传输"计算，利用了 SH 基函数的正交性来实现高效的积分计算。

---

这是一个经典的 **PRT（Precomputed Radiance Transfer）在 SH 域做卷积**的计算。我一步步拆解：

---

## 物理原理：`C_d = ρ_d · T`

漫反射颜色 = 反照率 × **到达该点的总入射光能量（经过遮挡/自阴影调制后）**

能量 T 需要用球面积分：`T = ∫ L(ω) · V(ω) · (n·ω) dω`
- L(ω) 是方向 ω 的光照
- V(ω) 是可见性/遮挡
- n·ω 是 Lambertian 余弦项
- V(ω)·(n·ω) 被 PRT 称为**传输函数**，编码了每个 Gaussian 的遮挡 + 几何信息

---

## 为什么要用 SH 点积？

球面上的函数积分计算很昂贵（需要对所有方向采样）。SH 的**正交性**可以高效地做这件事：

```
∫ L(ω) · T(ω) dω  ≈  Σ( c_j · c_j^t )
  ~~~~~~~~~~~       ~~~~~~~~~~~~~~~~~
  球面积分           SH系数点积的求和
```

其中：
- `c_j` = 光照 L(ω) 在 SH 基上的投影系数（`shs_direct_light`）
- `c_j^t` = 传输函数 T(ω) 在 SH 基上的投影系数（`shs_diffust_transfer`）

**原理**：如果两个函数都投影到同一组正交基（SH）上，它们的球面积分 ≈ 对应系数向量的点积。这样把 O(N²) 的求积变成了 O(N) 的向量点积。

---

## 为什么 +0.5 再 ReLU？

这里有两个不同的问题：

### 1. SH 系数天然有正有负（需要 ReLU）
SH 基函数是带正负瓣的，所以 `c_j` 和 `c_j^t` 都可能为负。它们的点积可以是负数，但**物理能量不能为负**，所以需要 ReLU 保正。

### 2. +0.5 是"环境光基线"
这是一个启发性偏置：

- 理论上，`Σ(c_j · c_j^t)` 的均值应该能正确表示平均光照
- 但实际上由于 SH 截断（只用了低阶）和训练不完美，某些极端角度下点积可能被压低到 0
- **+0.5 保证即使光照与传输完全反相，也有一个最小亮度兜底**——相当于加了一个淡环境光，避免出现全黑区域

你可以把它理解为传统渲染中的 `ambient term`（环境光项），但比固定值更灵活，因为 SH 点积本身还在提供方向性信息。

---

## 整个公式的工作流

```
光照 c_j        传输 c_j^t
   │                │
   └─── Σ(c_j · c_j^t)  ← SH域"卷积"（积分的近似）
              │
         + 0.5        ← 环境光基线
              │
          ReLU          ← 保正
              │
        × 反照率 ρ_d   ← 乘颜色
              │
         C_d(漫反射)
```

所以它本质上是一个**在 SH 空间做预计算光照传输的卷积操作**，利用了 SH 基函数的正交性来避免昂贵的方向采样积分。
